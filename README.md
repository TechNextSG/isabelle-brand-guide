# Isabelle's brands: brand guide

One HTML brand guide for the three brands founded by Isabelle Claus Teixeira:

| Page | Brand |
|------|-------|
| `index.html` | Overview: how the brands fit, side-by-side table, shared rules, co-branding |
| `bhdasia.html` | BHD Asia (Business and Human Development Consulting Pte Ltd) |
| `hummingbeing.html` | HummingBeing (Coaching & Somatics) |
| `tre-singapore.html` | TRE(TM) in Singapore |

Each brand page covers logo files (downloadable), colour swatches (click to copy), typography, photography, voice and copy rules.

- Static HTML, no build step. Shared styles in `assets/guide.css`, swatch copy + reveals in `assets/guide.js`.
- Links are clean (`bhdasia`, not `bhdasia.html`); GitHub Pages resolves them.
- Unlisted: every page is `noindex,nofollow` and `robots.txt` disallows all.
- Sources: bhdasia.com, hummingbeing.com, tre-in-singapore.com (as of October 2026). Colours were read from the live CSS and sampled from the logo files.
